Política de privacidad

Última actualización: 15 de noviembre de 2026

Esta política describe cómo la aplicación AxaFlow (en adelante, «la aplicación») trata la información al utilizarse para publicar contenido en el canal de YouTube del mismo nombre.

1. Qué es la aplicación

La aplicación es una herramienta de escritorio de uso personal, ejecutada de forma local por el titular del canal. No es un servicio web, no tiene usuarios registrados y no se distribuye a terceros.

2. Qué datos se tratan

La aplicación utiliza la API de datos de YouTube únicamente para:

  • Subir archivos de video al canal del titular.
  • Establecer el título, la descripción, las etiquetas y la miniatura.
  • Adjuntar pistas de subtítulos.
  • Consultar el estado de procesamiento de los videos subidos.

No se recopilan datos de espectadores, no se accede a información de otros canales y no se leen mensajes, comentarios ni datos personales de terceros.

3. Dónde se guardan las credenciales

El token de acceso OAuth 2.0 se almacena únicamente en el almacenamiento local del equipo del titular, en un archivo protegido por los permisos del sistema operativo. No se envía a ningún servidor propio ni de terceros.

4. Con quién se comparte

Con nadie. La aplicación no vende, alquila ni transfiere datos a terceros. La única comunicación externa es con los servidores de Google necesarios para operar la API de YouTube.

5. Uso limitado de datos de Google

El uso que la aplicación hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.

6. Conservación y eliminación

El token se conserva mientras el titular mantenga la autorización. Puede revocarse en cualquier momento desde myaccount.google.com/permissions, lo que invalida el acceso de inmediato. El archivo local puede eliminarse borrando el token del equipo.

7. Menores

La aplicación no está dirigida a menores y no recopila datos de ellos.

8. Cambios

Cualquier cambio en esta política se publicará en esta misma página con su fecha de actualización.
